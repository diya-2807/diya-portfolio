# Diya — Personal Portfolio

A sleek personal portfolio web application built with pure HTML, CSS, and modern vanilla JavaScript.

## Features
- **Modern Violet & Rose Design System**: Custom typography (`Space Grotesk` & `Plus Jakarta Sans`) with fluid responsive layout.
- **Interactive Navigation**: Sticky backdrop navigation, mobile drawer menu, and active scrollspy indicator.
- **Projects Showcase**: Featured project cards for **FinPulse**, **EcoTrack**, and **CampusConnect**.
- **Skills Matrix**: Categorized tags covering JavaScript, CSS, Frontend UI, Node.js, and Algorithms.
- **Contact Action**: Direct mailto and GitHub profile links.

## Running Locally
Open `index.html` in any browser. No dependencies or build steps required.
